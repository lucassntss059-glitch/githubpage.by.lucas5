# 🚀 Meu Portfólio - 1º Semestre de ADS

Olá! Este é o repositório do meu portfólio pessoal. Sou estudante de Análise e Desenvolvimento de Sistemas (ADS), atualmente no primeiro semestre. 

Meu foco principal de estudos tem sido no Back-end, onde gasto a maior parte das minhas horas lidando com algoritmos em **Python** e aprendendo os fundamentos e Orientação a Objetos com **Java**.

- **HTML5:** Estrutura semântica do site.
- **CSS3:** Estilização (foco em uma paleta Dark Mode: Preto, Branco e Azul).
- **JavaScript:** Lógica simples de front-end para interatividade básica.
